# T24 — PWA, cache e atualizações

Estado: concluída.
Marco: M4.
Dependências: [T22](T22.md), [T23](T23.md).
Requisitos: R14.

## Objetivo

Instalar e jogar offline com atualização controlada.

## Implementação

1. Adicionar manifesto, ícones próprios e vite-plugin-pwa com precache dos recursos essenciais.
2. Preparar escopo/base de subdiretório e aviso de atualização.
3. Salvar e aguardar ponto seguro antes de ativar atualização; tratar falha.

## Critérios de aceite

- [x] Cache inicial permite abrir e jogar sem rede.
- [x] Sem fonte/API remota necessária; ícones e manifesto têm caminhos corretos.
- [x] Atualização não recarrega silenciosamente uma partida ativa.

## Verificação

V17–V18 em build de produção; inspeção de cache e service worker.

## Limite de escopo

Dev server não comprova offline nem instalação.
