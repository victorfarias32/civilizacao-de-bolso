Estado: pendente.
Marco: M1.
Dependências: [T03](T03.md).

## Objetivo

Avançar por estações com comandos em ordem explícita.

## Implementação

1. Criar advanceSeason imutável e deriveSummary.
2. Validar ciclo alvo, IDs e opções de comando; registrar aplicados.
3. Separar ciclo lógico de relógio, UI e apresentação; preparar pontos explícitos para sistemas.

## Critérios de aceite

- [ ] Comando só afeta o ciclo previsto e IDs repetidos não reaplicam efeito.
- [ ] Avançar não modifica o estado de entrada.
- [ ] Nenhum resultado depende de horário, DOM ou Math.random.
