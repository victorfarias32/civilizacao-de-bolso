# Civilização de Bolso

Uma simulação de sociedades emergentes com partidas finitas, decisões coletivas e destinos memoráveis.

> Não é sobre fazer uma civilização crescer para sempre. É sobre descobrir o que uma civilização pode se tornar — e o que acontece quando sua história chega ao fim.

## Estado atual

Planejamento inicial. Este repositório contém documentação; ainda não há aplicativo, simulação implementada ou versão publicada.

## Documentação

- [Game Design Document](docs/GDD.md): experiência, sistemas, identidade visual e escopo.
- [Arquitetura proposta](docs/ARQUITETURA.md): tecnologias, separação de responsabilidades e desenvolvimento pelo celular.
- [Plano de implementação](docs/PLANO.md): marcos e critérios de validação.

As recomendações de design e os valores numéricos são hipóteses de prototipagem, sujeitas a testes.

## Objetivo técnico

Aplicação web responsiva e instalável como PWA, executada localmente, sem backend obrigatório, API paga ou inteligência artificial externa. Desenvolvimento e publicação possíveis com um ambiente na nuvem acessado pelo celular Android.

## Próximo marco

Uma comunidade de 12 habitantes que coleta e consome alimento, reage à política de trabalho e registra consequências observáveis.
